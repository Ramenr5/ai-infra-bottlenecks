## 1. Forward thesis

The same agentic-AI inflection this wiki tracks on the demand side — Claude Code going 4%→20% of GitHub commits, Computer Use, AI-autonomous cyberattacks — is now the primary growth engine for two enterprise-software incumbents one layer up: **CrowdStrike** (securing the exploding "agentic SaaS attack surface") and **ServiceNow** (orchestrating/governing the agentic enterprise). Both convert agent proliferation into hard ARR today (CRWD agentic-identity product +300% YoY; NOW AI commitments $1.5B for 2026). The forward bet is that AI agents are a **net tailwind** rather than a disintermediation threat — but the wiki's own value-capture evidence warns rents may migrate to the model labs, making this a tailwind-vs-disruption race the incumbents must keep winning.

## 3. What would have to be true

- Agent adoption keeps compounding **and generalizes beyond code** (the 20%-of-commits curve is the proof-point; thesis needs it to repeat across IT/security/finance workflows). *(partly sourced)*
- Net effect is **additive**: agents create more security/orchestration surface than they automate away. *(inferred — the crux)*
- Incumbents capture it vs. (a) model labs moving up-stack, (b) Microsoft/hyperscaler bundling, (c) agents collapsing the workflow layer.
