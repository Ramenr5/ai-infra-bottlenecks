# Application & software

**The top of the stack — where AI meets the end user/enterprise.** This is the "stock-picker's layer" of [[AI value capture across the stack]]: it captured **~half of the $37B enterprise AI spend in 2025** ([[Menlo - State of Enterprise AI (2025)]]), but it is **fragmented and contested**, so winners keep rents and losers get commoditized. The investment job here is selection, not beta.

## The layer's defining tension
- **Bull:** agentic AI is a net tailwind — cheaper inference ([[Disaggregated inference (Rubin CPX)]]) → more agents deployed → more application surface to sell (security, orchestration, data, workflow). Real ARR is landing *now*.
- **Bear:** value migrates **up** to the model labs ([[SemiAnalysis - AI Value Capture (2026)]]) and/or the layer gets **commoditized** from three directions — hyperscaler bundling (Microsoft Agent 365), model-lab agent SDKs moving up-stack, and seat-erosion (agents replace the seats SaaS sells against).
- **Net:** a layer where the *pie grows* but the *rent is fought over* — hence stock-picking.

## The two sub-layers
**1. Model / frontier labs (the upstream of this layer).** Highest rent today, **least durable** — the open-weight swing factor ([[Open-weight commoditization (the swing factor)]]) threatens to commoditize it. Names: [[Anthropic]] (40% of enterprise LLM spend), [[OpenAI]], [[Alphabet|Google DeepMind]], [[DeepSeek]] (open-weight challenger). See [[AI value capture across the stack]].

**2. Agentic application / SaaS (the monetizers).** Sell agents + the governance/security/data around them.

## Where the rent lands (tradable read)
- **The pie is real** ([[Menlo - State of Enterprise AI (2025)]]) — don't dismiss the layer just because the labs are loud.
- **Selection rule** (from [[AI value capture across the stack]]): favor app names with a *structural moat the agents can't route around* — proprietary data/ontology ([[Palantir]]), the security/identity chokepoint ([[CrowdStrike]]), or system-of-record lock-in ([[ServiceNow]], [[Salesforce]]) — over thin workflow wrappers.
- **Avoid** seat-priced SaaS with no data moat (most exposed to seat-erosion) and point solutions a hyperscaler can bundle for free.

## Leading indicators
- Agentic ARR compounding (Agentforce, Now Assist, CRWD agentic) = layer confirm.
- **Pricing-model shift** seat → metered/outcome (the seat-erosion tell).
- Hyperscaler bundling moves (Microsoft Agent 365 traction) = rent compression.
- **Open-weight parity** ([[Open-weight commoditization (the swing factor)]]) — commoditizes the upstream labs, which *helps* the app layer (cheap intelligence as input).
