# Identity security in the AI era (2026)

**Publishers:** CrowdStrike IR (SGNL acquisition), Okta newsroom (AI Agents at Work 2026 survey), market sizing
**URLs:** [CRWD–SGNL](https://ir.crowdstrike.com/news-releases/news-release-details/crowdstrike-acquire-sgnl-transform-identity-security-ai-era) · [Okta AI Agents 2026](https://www.okta.com/newsroom/articles/ai-agents-at-work-2026-agentic-enterprise-security/)

## Headline

The agentic-AI attack surface is a **real, sized, fast-growing security category** — not a narrative invention. AI agents are exploding the population of **non-human identities (NHIs)** to govern, and identity security is becoming one of cyber's largest segments. This sources the "agentic attack surface" links in the [CRWD+NOW narrative](../../narratives/2026-06-01 CRWD %2B NOW.md).

| Metric | Value |

| **Machine identities per human user** | **~45** (and rising fast with AI agents) |
| Agent adoption | by 2027, half of GenAI-using companies also adopt agents (Deloitte) |
| **CRWD Falcon Next-Gen Identity Security ARR** | **>$520M ending ARR, +34% YoY** |
| **CRWD acquiring SGNL** (Jan 2026) | continuous identity for human / NHI / AI identities — real-time grant/revoke |

## The adoption-friction signal (demand pull for security)

- **86%** of IT leaders call AI agents "mission-critical / very important"
- but only **27%** say their identity systems can govern NHIs at scale
- **69%** say security concerns are *slowing* agent adoption; top barriers: data leakage (83%), over-privileged access (80%)

→ Security is a **gating bottleneck on agent adoption** — which is bullish for the security vendors solving it (CRWD, Okta, CyberArk) and a read-through to [[ServiceNow]]'s "secure the agentic enterprise" (Armis) positioning.
