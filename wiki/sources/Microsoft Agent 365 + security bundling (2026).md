# Microsoft Agent 365 + security bundling (2026)

## Headline — Microsoft is the giant on BOTH companies' turf

The Microsoft bundling threat is the canonical bear for [[CrowdStrike]] — **and** Microsoft's **Agent 365** (Nov 2025) puts it in direct competition with [[ServiceNow]]'s agent-control-plane bet. This is the "Microsoft bundling" gap from the [narrative](../../narratives/2026-06-01 CRWD %2B NOW.md), now sourced — and it's bigger than expected.

## vs CrowdStrike — bundling (bear, real)

- Microsoft bundles **Defender** security into M365/E5; the market view: *"because Microsoft bundles security with their other offerings, they don't need to be as good as CrowdStrike to win"*
- The standing platform-bundle threat to standalone security (CRWD, Palo Alto) from a diversified giant — recognized risk, not new, but persistent

## vs ServiceNow — Agent 365 = coopetition (the important twist)

- **Microsoft Agent 365** (Nov 2025): control, track, register, secure AI agents — *Microsoft's own "agent governance + registry" layer*. This **directly overlaps [[ServiceNow]]'s "agent control plane" thesis** — Microsoft wants to be the place enterprises govern their digital workforce.
- **But also partnership:** NOW + Microsoft deepened integration — ServiceNow **AI Control Tower** governance extends across Agent 365; ServiceNow agents auto-appear in Agent 365; NOW AI specialists operate inside M365 (Outlook/Word/PowerPoint) with metered usage across both.
- Net: **coopetition.** Microsoft is simultaneously NOW's distribution partner *and* a competitor for the exact governance/control-plane layer NOW is betting on.

## Why it matters (narrative gaps filled)

- **CRWD:** confirms the Defender bundling bear — a margin/share overhang on the agentic-security bull.
- **NOW:** the control-plane (narrative **L5**) faces a **hyperscaler-scale competitor** — Microsoft Agent 365 — not just commoditizing MCP plumbing below but a rival governance layer above. Sharpens the "does NOW *win* the governance layer?" inferred bet: now it's NOW + the labs' SDKs + **Microsoft Agent 365** all contesting it.
