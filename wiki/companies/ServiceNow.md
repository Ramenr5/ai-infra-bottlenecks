# ServiceNow

US enterprise workflow / IT-service-management platform (NYSE: NOW). **Application-layer AI beneficiary** positioning itself as the **orchestration + governance control plane for the "agentic enterprise"** — the layer that decides which AI agent/LLM runs a workflow and governs it end-to-end. AI is now its fastest-growing vector (Now Assist + agentic commitments).

## The agentic-AI angle (the thesis link)

- **AI-specific commitments revised UP to $1.5B for 2026** (from $1B — a 50% raise) — the cleanest single tell that agentic adoption is monetizing
- **Now Assist** >$600M ACV tracking to $1B; deals with 3+ Now Assist products +70% YoY
- **"The quarterback" positioning** (CEO Bill McDermott, Q1 FY26): ServiceNow *"figures out which agent or LLM to use"* while managing governance end-to-end — the explicit **agent control-plane** claim
- **Armis acquisition** (security) — pushes NOW into the secure-the-agentic-enterprise space (overlapping [[CrowdStrike]]'s turf)

## Why it matters for the thesis

- **Agent control plane = the bet.** If AI agents proliferate (the wiki's agentic inflection: [[SemiAnalysis - Claude Code Is The Inflection Point]]), someone orchestrates + governs them. NOW claims that layer. McDermott's "quarterback" quote *partly sources* what was an inferred link in the [narrative](../../narratives/2026-06-01 CRWD %2B NOW.md).
- **Value-capture test case:** bull = agents need orchestration NOW provides; bear = [[SemiAnalysis - AI Value Capture (2026)]] (value to labs) + "AI eats SaaS" seat-erosion compress the workflow layer.

## Risks
- "AI eats SaaS" — if agents collapse workflows, seat-based ITSM value erodes (the disintermediation case)
- Value migration to model labs ([[SemiAnalysis - AI Value Capture (2026)]])
- **Orchestration commoditization:** [[MCP and the Agentic AI Foundation (2026)|MCP]] is now an open Linux-Foundation standard — the agent↔tool *protocol* commoditizes, so NOW's moat must sit in the **governance / business-context / which-agent layer above MCP** (the "quarterback"), not the pipes. Whether NOW wins that layer vs. hyperscalers + the labs' own agent SDKs is the open question.
- Hyperscaler/Microsoft bundling of workflow + AI
