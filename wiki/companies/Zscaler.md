# Zscaler

**The zero-trust / Secure Service Edge (SSE) leader** (NASDAQ: ZS) — cloud-delivered secure access between users/apps/agents. The "network-control-plane" angle on the [AI cybersecurity narrative](../../narratives/2026-06-02 AI cybersecurity.md).

## Key figures (FY2026, VERIFY)
- **Q3 FY26 revenue +25% YoY to $850.5M; ARR +25% to $3,525M**; FY26 ARR guide raised to ~24%.

## Why it matters for the thesis
- Agents generate **traffic** (egress, tool calls, API access) that needs the same **zero-trust/least-privilege** controls as human users — so agent proliferation is a read-through tailwind for SSE. `(Read-through; agent-traffic security is adjacent to Zscaler's core, partly inferred.)`
- A platform play (Zero Trust Exchange) with its own AI ambitions (data security, AI-app control) — better positioned vs Microsoft bundling than a point tool, weaker than [[Palo Alto Networks]]'s breadth.

## Risks
- Less direct to the **identity** chokepoint than [[Palo Alto Networks]]/[[Okta]]/[[CrowdStrike]]; Microsoft bundling (Entra/Defender for Cloud Apps); SASE competition from PANW.
