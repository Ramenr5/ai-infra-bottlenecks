# Sivers Semiconductors

**Micro-cap InP-laser chokepoint for co-packaged optics** (Nasdaq Stockholm: SIVE; ~$130m mcap). Makes **laser arrays / external light sources (ELS)** — the light *source* for CPO, which silicon can't generate on-die.

## The thesis
- **CPO needs an external laser** (CW light fed into the silicon PIC) → Sivers' InP laser arrays are a genuine **chokepoint** in the [[Networking & interconnect]] optics buildout.
- **GlobalFoundries** silicon-photonics partnership + **O-Net/Enablence ELS module** for AI-datacenter/HPC CPO roll-out.

## Investment read — Tier 3 *architecture bet* (high upside, NOT a clean toll)
- Per [[AI value capture across the stack]], Sivers is **architecture-dependent**: it wins **only if CPO beats pluggable optics** at scale. If pluggables persist or laser sourcing gets second-sourced/designed around, the chokepoint thesis weakens.
- **Micro-cap, high-beta** (±60% on single headlines; a short-seller target). Venture-grade exposure to the CPO transition — size accordingly.
